# Mix N' Match Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- React web/PWA client
- Expo/React Native mobile client
- shared fighter model and compatibility engine
- ranked discovery with explainable match reasons
- connect/pass/undo and training-session planning
- local-first persistence and release configuration

## Improving

- web/mobile parity
- real-device QA
- accessibility and safety-copy polish
- release-readiness checks

## Exploring

- real accounts and mutual connection requests
- messaging and push notifications
- gym verification
- synced training history

## Product boundary

Keep one shared domain model across web and mobile. Add backend complexity only when real multi-user behavior requires it.
