# Contributing to Mix N' Match

Mix N' Match is a React web/PWA + Expo/React Native product with shared fighter and compatibility logic.

Before a pull request, follow the README setup and run the existing web, shared-core, and mobile validation commands. Shared-domain changes should be checked in both clients.

Prefer changes that improve the discovery → connect → plan → complete training loop, accessibility, safety, reliability, and web/mobile parity.

A merged commit is not automatic approval for a production deployment.
